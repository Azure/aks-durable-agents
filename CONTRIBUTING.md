# Contributing

This project welcomes contributions and suggestions. It is experimental source,
not a qualified preview release or a supported production service. Read the
[status and development pins](README.md) and [development checks](docs/development.md)
before changing the assembly. Keep validation claims tied to checks actually run;
offline fixtures do not qualify a live deployment.

Send changes as pull requests to the canonical
[Azure/aks-durable-agents repository](https://github.com/Azure/aks-durable-agents).
Describe compatibility changes, especially image/fixture interfaces and retained
journal, receipt or model-ledger state. Do not include credentials, real tenant or
resource identifiers, private repository links, or private test evidence.

## Contributor License Agreement

Most contributions require a Contributor License Agreement (CLA) declaring that
you have the right to, and do, grant us the rights to use your contribution.
See [Microsoft Contributor License Agreements](https://cla.opensource.microsoft.com).
Follow the CLA check on your pull request; maintainers must confirm the applicable
CLA requirements before merging. A missing check does not waive those requirements.

## Code of Conduct and security

This project adopts the [Microsoft Open Source Code of Conduct](CODE_OF_CONDUCT.md).
Report vulnerabilities privately using [SECURITY.md](SECURITY.md), not public issues
or pull requests. For non-security bugs and questions, see [SUPPORT.md](SUPPORT.md).
